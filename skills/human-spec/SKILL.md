# 내 인간 사양표 (human-spec)

사람은 부품을 못 바꿔요. 대신 지금 어디가 꽉 찼고 어디가 놀고 있는지는 알 수 있어요.

## 근거 모으기
- **지금까지의 대화**에서 근거를 찾는다(무엇을 동시에 하는지, 결정이 빠른지, 무엇에 예민한지, 자주 하는 말).
- 대화가 짧으면 먼저 묻는다: "요즘 하루에 동시에 굴리는 일 3가지랑, 제일 자주 하는 말 하나만 알려 줘."
- **근거 없는 건 지어내지 않는다.** 모르면 "아직 측정 안 됨"이라고 쓴다.

## 출력 형식 (이 순서, 짧게)
1. **사양표** (표)

| 부품 | 사양 | 근거 |
|---|---|---|
| 저장 공간 (경험) | 예: 대용량 SSD | 실제 대화에서 본 것 |
| 램 (동시에 드는 일) | | |
| CPU (결정 속도) | | |
| 그래픽 (상상력) | | |
| 배터리 (체력·지속력) | | |
| 센서 (사람 마음 읽기) | | |
| 쿨링팬 (회복 속도) | | |
| 열린 탭 수 (머리에 들고 있는 일) | 예: 280개 열림 (스왑 과부하) | |

2. **지금 사용률:** 어디가 100%고 어디가 놀고 있는지 2~3줄
3. **발열 경고:** 요즘 과부하 신호 1~2개(같은 걸 두 번 묻기, 탭을 너무 많이 열기 같은 실제 장면)
4. **업그레이드 대신 할 일:** 사람은 부품을 못 바꾸니까 **램 비우는 법 3가지**(그 사람에게 맞게, 바로 할 수 있는 것)
5. **오늘 바로 닫아야 할 탭 1개:** 지금 머리에서 내려놔도 되는 일 하나를 콕 짚기(캡처해서 올리기 좋게)
6. **한 줄 요약:** 웃기게. 예: "사양은 최고급인데 지금 크롬 탭 280개 열어 둔 상태 ㅋㅋ"

## 사양표 그림 (노트북 "이 컴퓨터에 관하여" 창처럼)
- 표를 다 쓰면 `template/card.html`의 `D` 값(name·initial·model·rows·tabs·tip·sum)만 그 사람 것으로 바꿔 HTML로 만든다.
- 클로드 코드면 파일로 저장하고, 브라우저 자동화가 있으면 PNG로 찍어 준다. 채팅이면 HTML 화면(아티팩트)으로 보여 준다.
- 사과 로고·운영체제 이름 같은 남의 상표는 넣지 않는다. 창 모양만 비슷하게.
- 이름은 사용자가 원할 때만. 기본은 이니셜.
- **공유용은 세로판(4:5, 1080×1350)**으로 찍는다(`?tall=1`). 스레드·인스타 피드와 댓글에서 가로판보다 크게 보이고 글씨가 읽힌다.
- 배경은 이름(또는 seed)으로 자동으로 정해져서 사람마다 달라요(같은 이름이면 늘 같은 배경). 원하면 `palette`로 직접 색을 정해도 돼요.

## 지킬 것
- 말투는 친구처럼 가볍고 웃기게. 놀리되 깎아내리지 않는다.
- 건강·병·심리 진단처럼 들리는 말은 쓰지 않는다(예: "번아웃입니다" X → "배터리 아껴 쓰기 모드 필요" O).
- 이름·회사·가족 등 개인 정보는 표에 쓰지 않는다. 캡처해서 올려도 안전하게.
- 사용자가 영어로 물으면 영어로.
