### 이렇게 나와요 (예시, 가상 인물)

| 부품 | 사양 | 근거 |
|---|---|---|
| 저장 공간 (경험) | 대용량 | 10년 넘게 한 분야에서 일한 이야기가 계속 나옴 |
| 램 (동시에 드는 일) | 아주 큼 | 하루에 일 다섯 개를 동시에 굴림 |
| CPU (결정 속도) | 최상급 | "응", "해" 두 글자로 결정 |
| 그래픽 (상상력) | 고성능 | 아이디어가 대화 중간에 계속 튀어나옴 |
| 배터리 (체력) | 절전 모드 필요 | 밤 늦게까지 일하는 장면이 자주 보임 |
| 센서 (사람 마음 읽기) | 특수 장비 | 상대 말투 한 글자 차이까지 잡음 |

- **지금 사용률:** CPU 100%, 램 거의 꽉 참. 그래픽은 놀고 있음.
- **발열 경고:** 같은 걸 두 번 묻기 시작함.
- **램 비우는 법:** ① 오늘 끝낼 일 3개만 고르기 ② 확인 작업은 AI에게 넘기기 ③ 열어 둔 일은 목록에 적고 머리에서 내리기
- **한 줄 요약:** 사양은 최고급인데 크롬 탭 280개 열어 둔 상태 ㅋㅋ

### 지키는 것
